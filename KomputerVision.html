I

Pendahuluan

Latar belakang, tujuan, dan ruang lingkup proyek computer vision ini

1.1 Latar Belakang

Perkembangan teknologi Computer Vision (Visi Komputer) dalam beberapa tahun terakhir telah melahirkan berbagai arsitektur jaringan saraf tiruan (deep learning) yang mampu mendeteksi dan mengklasifikasikan objek secara instan. Salah satu model state-of-the-art paling populer dan efisien di industri saat ini adalah YOLO (You Only Look Once), khususnya varian YOLOv8 yang dikembangkan oleh Ultralytics. YOLOv8 terkenal karena kecepatannya yang sangat tinggi tanpa mengorbankan akurasi mean Average Precision (mAP).

Meskipun deteksi visual pada layar komputer sangat informatif, pada implementasi dunia nyata—seperti sistem pemantauan ruang kerja, alat bantu tuna netra (assistive technology), maupun asisten pintar—pengguna sering kali tidak dapat memantau monitor secara terus-menerus. Oleh karena itu, diperlukan integrasi modalitas feedback lain yang bersifat auditif (suara). Dengan menggabungkan deteksi visual kamera dan Text-to-Speech (TTS) offline berbahasa Indonesia, sistem dapat langsung mengumumkan nama benda yang tertangkap di depan kamera tanpa mengharuskan pengguna memandang layar.

1.2 Tujuan Proyek

Tujuan utama dari perancangan dan pembuatan skrip yolo_suara.py adalah:

  • Membangun sistem deteksi objek real-time menggunakan webcam laptop/komputer dengan model YOLOv8 Nano
  • Memfilter dan memetakan objek-objek umum di area meja kerja (seperti handphone, jam, buku, laptop, botol, dll.) ke dalam nama Bahasa Indonesia
  • Mengintegrasikan mesin Text-to-Speech (TTS) bawaan Windows (SAPI5) yang bekerja 100% offline, gratis, dan tanpa ketergantungan koneksi internet
  • Menerapkan arsitektur asynchronous non-blocking dan mekanisme speech cooldown timer agar video stream webcam tetap berjalan mulus (60+ FPS) tanpa mengalami freeze/stuttering saat komputer berbicara
  • Menyederhanakan penamaan label (seperti mengubah 'clock/watch' menjadi 'Jam') untuk menghasilkan artikulasi suara yang jernih dan mudah dipahami pengguna

1.3 Ruang Lingkup Sistem

Sistem ini difokuskan pada pengenalan objek-objek yang lazim ditemukan di atas meja kerja berdasarkan bobot pretrained model COCO (Common Objects in Context). Tabel berikut merinci daftar kelas objek yang dikonfigurasi dalam sistem:

Spesifikasi dan Kebutuhan Sistem

Persyaratan hardware, software, dan dependencies untuk menjalankan sistem

2.1 Kebutuhan Perangkat Keras (Hardware)

Untuk menjalankan sistem ini secara optimal tanpa kendala lag, spesifikasi minimum yang direkomendasikan adalah sebagai berikut:

  • Prosesor (CPU): Intel Core i3 / AMD Ryzen 3 atau lebih tinggi
  • Kartu Grafis (GPU): Opsional (Bisa berjalan mulus di CPU murni berkat efisiensi YOLOv8 Nano)
  • Kamera: Webcam internal laptop (resolusi 720p) atau Webcam USB eksternal
  • Audio: Speaker internal atau headphone/earphone untuk mendengarkan keluaran suara TTS
  • Memori (RAM): Minimal 4 GB (disarankan 8 GB ke atas)

2.2 Kebutuhan Perangkat Lunak (Software)

Sistem dibangun di atas ekosistem Python modern pada platform sistem operasi Windows. Komponen perangkat lunak meliputi:

  • Sistem Operasi: Microsoft Windows 10 atau Windows 11 (64-bit)
  • Runtime Python: Python versi 3.10 atau 3.11
  • Editor Kode / IDE: Visual Studio Code, PyCharm, atau terminal PowerShell

4.2 Mengatasi Masalah Latensi Audio (Non-Blocking TTS)

Tantangan terbesar dalam menggabungkan Computer Vision dengan Text-to-Speech adalah latensi I/O audio. Pada pendekatan konvensional menggunakan sintaks synchronous (seperti pyttsx3.runAndWait() atau SAPI5 Speak mode blocking), prosesor video akan terhenti (freeze) selama mesin audio sedang membaca kata. Jika mesin membaca kata selama 2 detik, maka video kamera akan membeku selama 2 detik.

Solusi yang diterapkan pada skrip yolo_suara.py adalah memanfaatkan parameter flags=1 pada metode Speak SAPI5:

tts_speaker.Speak(text_to_say, 1)  # 1 melambangkan SPF_ASYNC

Flag bernilai 1 ini memerintahkan sistem operasi Windows untuk memutar audio pada thread latar belakang terpisah (background worker thread), sehingga thread utama OpenCV dapat langsung melanjutkan pembacaan frame kamera berikutnya pada milidetik yang sama tanpa ada penurunan FPS.

4.3 Mekanisme Speech Cooldown Timer

Ketika sebuah benda (misalnya handphone) diletakkan di atas meja, objek tersebut akan terdeteksi di setiap frame kamera (30-60 kali per detik). Jika suara dipicu pada setiap frame, sistem akan mengalami penumpukan antrean audio (audio stuttering / voice spam) yang sangat mengganggu.

Untuk mengatasi hal ini, diterapkan variabel GLOBAL_SPEECH_COOLDOWN sebesar 3.5 detik. Sistem mencatat timestamp time.time() terakhir kali suara dikeluarkan, dan menolak pemanggilan suara baru hingga selisih waktu telah melampaui 3.5 detik. Durasi ini terbukti ideal untuk memberi jeda alami pada percakapan.

V

Pembahasan Kode Program Lengkap

Kode sumber lengkap dan bedah teknis setiap bagian program

Kode Sumber Lengkap yolo_suara.py

import cv2
import time
import win32com.client
from ultralytics import YOLO

# ==========================================
# INISIALISASI AUDIO (WINDOWS SAPI5 NATIVE)
# ==========================================
try:
    tts_speaker = win32com.client.Dispatch("SAPI.SpVoice")
    # Kecepatan suara santai & jelas (-2)
    tts_speaker.Rate = -2
    print("[AUDIO] Engine Windows SAPI5 TTS Aktif.")
except Exception as e:
    print(f"[AUDIO ERROR] Gagal mengaktifkan SAPI5: {e}")
    tts_speaker = None

# Jeda waktu global antar penyebutan benda (3.5 detik)
GLOBAL_SPEECH_COOLDOWN = 3.5
last_global_speech_time = 0

def play_sound(text_to_say):
    """
    Mengucapkan nama benda secara async dengan jeda waktu global (3.5 detik).
    """
    global last_global_speech_time
    current_time = time.time()

    if current_time - last_global_speech_time >= GLOBAL_SPEECH_COOLDOWN:
        print(f"[🔊 SUARA] PC Bersuara: '{text_to_say}'")
        if tts_speaker:
            try:
                tts_speaker.Speak(text_to_say, 1) # 1 = Async
            except Exception as err:
                print(f"[AUDIO ERROR] Gagal bicara: {err}")
        last_global_speech_time = current_time

# ==========================================
# PEMETAAN BENDA DI MEJA DARI DATASET COCO YOLOV8N
# ==========================================
DIRECT_YOLO_MAPPING = {
    # 1. Handphone
    'cell phone': 'Handphone',

    # 2. Jam (Disederhanakan menjadi "Jam" agar suara TTS diucapkan sangat jelas)
    'clock': 'Jam',
    'watch': 'Jam',

    # 3. Buku
    'book': 'Buku',

    # Benda Meja Umum Lainnya
    'laptop': 'Laptop',
    'mouse': 'Mouse',
    'keyboard': 'Keyboard',
    'bottle': 'Botol',
    'cup': 'Gelas',
    'scissors': 'Gunting'
}

# ==========================================
# PROGRAM UTAMA WEBCAM REAL-TIME
# ==========================================
def main():
    print("\n==================================================")
    print("    DETEKSI BENDA MEJA (YOLOV8N) + SUARA INDONESIA")
    print("==================================================")
    print("Memuat model YOLOv8...")

    try:
        model = YOLO("yolov8n.pt")
        print("[BERHASIL] Model YOLOv8 Standar Aktif!")
    except Exception as e:
        print(f"[ERROR] Gagal memuat model YOLO: {e}")
        return

    # Inisialisasi Kamera Web Utama (0)
    print("\nMembuka kamera webcam...")
    cap = cv2.VideoCapture(0)

    if not cap.isOpened():
        print("[ERROR] Kamera webcam tidak dapat diakses!")
        return

    print("\n[BERHASIL] Kamera Aktif!")
    print("--> Penyebutan Jam Tangan telah diubah menjadi 'Jam' agar diucapkan jernih.")
    print("--> Tekan 'q' pada jendela video untuk keluar.\n")

    while True:
        ret, frame = cap.read()
        if not ret:
            print("[ERROR] Gagal mengambil gambar dari kamera.")
            break

        # Deteksi dengan YOLO (confidence 0.25)
        results = model.predict(frame, conf=0.25, verbose=False)

        detected_in_this_frame = set()

        for result in results:
            boxes = result.boxes
            for box in boxes:
                cls_id = int(box.cls[0])
                class_name = model.names[cls_id].lower()
                conf = float(box.conf[0])

                if class_name in DIRECT_YOLO_MAPPING:
                    indonesian_name = DIRECT_YOLO_MAPPING[class_name]
                    detected_in_this_frame.add(indonesian_name)

                    x1, y1, x2, y2 = map(int, box.xyxy[0])

                    # Gambar Bounding Box Hijau & Label Indonesia
                    label = f"{indonesian_name} ({conf:.2f})"
                    cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 3)
                    cv2.putText(
                        frame,
                        label,
                        (x1, max(30, y1 - 10)),
                        cv2.FONT_HERSHEY_SIMPLEX,
                        0.7,
                        (0, 255, 0),
                        2
                    )

                    print(f"[DETEKSI] Terdeteksi: '{class_name}' -> '{indonesian_name}' (Akurasi: {conf:.2f})")

        # Bersuara untuk objek terdeteksi
        for obj_name in detected_in_this_frame:
            play_sound(obj_name)

        # Petunjuk layar
        cv2.putText(
            frame,
            "Benda Meja: Handphone, Jam, Buku, Laptop, Botol, Gelas | 'q' Exit",
            (10, 25),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.5,
            (255, 255, 255),
            1
        )

        cv2.imshow("Deteksi Benda Meja (YOLOv8 Standar)", frame)

        if cv2.waitKey(1) & 0xFF == ord('q'):
            print("\nProgram dihentikan oleh pengguna.")
            break

    cap.release()
    cv2.destroyAllWindows()
    print("Selesai.")

if __name__ == "__main__":
    main()

5.1 Bedah Teknis Baris Kode

A. Baris 1 - 4: Import Modul

Modul cv2 menyediakan fungsi pengolahan citra dan penampil video. Modul time digunakan untuk perhitungan selisih detik. win32com.client mengaktifkan antarmuka COM Windows untuk berkomunikasi dengan voice engine SAPI5. Sedangkan from ultralytics import YOLO memuat modul deep learning YOLO.

B. Baris 7 - 16: Inisialisasi SAPI5 & Pengaturan Kecepatan

win32com.client.Dispatch('SAPI.SpVoice') memanggil instance COM suara native Windows. Nilai tts_speaker.Rate diatur ke -2. Nilai negatif ini memperlambat tempo ucapan sedikit agar setiap suku kata dalam Bahasa Indonesia terdengar lebih tegas, tenang, dan tidak terburu-buru.

C. Baris 19 - 37: Fungsi play_sound() dan Cooldown

Fungsi play_sound menerima argumen nama benda yang akan disuarakan. Logika current_time - last_global_speech_time >= 3.5 memastikan jeda antar kata minimal 3.5 detik. Parameter kedua pada tts_speaker.Speak(text_to_say, 1) bernilai 1 (SVSFlagsAsync), yang menjamin perintah suara langsung kembali tanpa memblokir thread video.

D. Baris 41 - 59: Dictionary DIRECT_YOLO_MAPPING

Kamus ini berfungsi ganda: sebagai whitelist (hanya objek dalam kamus ini yang diproses, mengabaikan objek lain seperti 'person' atau 'chair') sekaligus sebagai translasi bahasa ke Bahasa Indonesia. Sebagai catatan khusus, kelas 'clock' dan 'watch' sengaja dipetakan menjadi 'Jam' agar pelafalan fonetik Windows terdengar sempurna tanpa aksen kaku.

E. Baris 64 - 87: Inisialisasi Model & Kamera

Fungsi main() memuat model('yolov8n.pt') dan membuka cv2.VideoCapture(0). Indeks 0 merepresentasikan kamera default Windows. Dilakukan pengecekan kondisi cap.isOpened() untuk mencegah error crash jika webcam sedang digunakan oleh aplikasi lain.

F. Baris 89 - 148: Loop Pemrosesan Citra Real-Time

Setiap putaran membaca frame citra dari kamera. model.predict(frame, conf=0.25, verbose=False) melakukan forward pass deteksi objek dengan ambang keyakinan (confidence threshold) 25%. Hasil deteksi yang lolos filter digambari kotak persegi hijau (0, 255, 0) dengan ketebalan 3 piksel dan teks label. Himpunan detected_in_this_frame digunakan agar nama objek yang sama hanya disuarakan satu kali per frame.

G. Baris 149 - 155: Terminasi dan Pembersihan Memori

Ketika pengguna menekan tombol 'q' (cv2.waitKey(1) & 0xFF == ord('q')), perulangan berhenti. cap.release() membebaskan perangkat keras webcam dari penguncian memori, dan cv2.destroyAllWindows() menutup seluruh jendela grafis.

Kesimpulan dan Rekomendasi

Hasil akhir proyek dan saran pengembangan di masa mendatang

7.1 Kesimpulan

Berdasarkan hasil perancangan, implementasi, dan pengujian program yolo_suara.py, dapat disimpulkan bahwa:

  • Model YOLOv8 Nano (yolov8n.pt) terbukti sangat handal dan ringan untuk mendeteksi berbagai benda meja kerja secara real-time pada perangkat komputer standar tanpa memerlukan GPU diskrit berkemampuan tinggi
  • Integrasi antarmuka COM Windows SAPI5 menyediakan solusi Text-to-Speech yang efisien, tanpa biaya, dan bekerja 100% offline
  • Penerapan parameter asynchronous (flag 1) berhasil mengeliminasi stuttering/lag pada tampilan kamera, sehingga streaming video tetap berjalan mulus pada kecepatan frame penuh
  • Mekanisme cooldown timer (3.5 detik) dan penyederhanaan label menjadi 'Jam', 'Handphone', 'Buku', dan sejenisnya terbukti efektif menghasilkan feedback suara yang natural, jernih, dan tidak mengganggu

7.2 Rekomendasi Pengembangan Lebih Lanjut

Untuk pengembangan dan peningkatan kemampuan sistem di masa mendatang, disarankan beberapa inovasi berikut:

  • Fine-Tuning Custom Dataset: Melakukan pelatihan model tambahan (custom training) untuk mengenali benda-benda meja yang lebih spesifik, seperti dompet, kartu identitas, kunci kendaraan, atau jenis obat tertentu
  • Estimasi Jarak & Posisi Objek: Menambahkan logika estimasi posisi koordinat relatif benda (kiri, tengah, kanan) pada layar kamera untuk diumumkan bersama nama benda (contoh: 'Handphone di sebelah kiri')
  • Deployment ke Perangkat Edge: Memigrasikan arsitektur ini ke perangkat mini PC seperti Raspberry Pi atau NVIDIA Jetson Nano untuk dijadikan perangkat portabel (kacamata pintar atau kalung pintar tuna netra)
  • Proyek ini memiliki potensi besar untuk dikembangkan menjadi aplikasi pintar, seperti kursi roda pintar atau alat bantu portabel lainnya, yang dirancang khusus untuk memandu penyandang tunanetra dalam berjalan di lingkungan sekitar secara mandiri dan aman
